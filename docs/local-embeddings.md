# Локальный многоязычный semantic search

Сервис использует зафиксированную квантованную ONNX-сборку BGE-M3 (`Xenova/bge-m3`, `4de13258303883538bd53b696b452bf8099f0858`).
Модель применяется только для поиска фрагментов инструкции, относящихся к ТО, очистке, стерилизации и расходникам. PDF и embeddings не отправляются во внешний сервис.

## Установка

На сервере один раз выполните:

```bash
./scripts/install-bge-m3.sh /var/lib/pdf2tz/models/bge-m3/4de13258303883538bd53b696b452bf8099f0858
```

Файлы модели не входят в Git. Для запуска задайте:

```bash
PDF2TZ_EMBEDDINGS_ENABLED=true
PDF2TZ_EMBEDDING_MODEL_PATH=/var/lib/pdf2tz/models/bge-m3/4de13258303883538bd53b696b452bf8099f0858
```

Без `PDF2TZ_EMBEDDINGS_ENABLED=true` приложение использует только структурный селектор и не пытается загружать модель. При включённой функции приложение завершит запуск с понятной ошибкой, если отсутствуют `model.onnx` или `tokenizer.json`.

## Контроль и обновление

Автообновления отсутствуют. Версия закреплена в скрипте и документации. Для эксперимента с иной версией используйте другой каталог и отдельную конфигурацию; исходная модель остаётся неизменной. Квантованная сборка занимает около 600 МБ на диске и требует ориентировочно 3–5 ГБ RAM для процесса приложения и обработки PDF.
